Vertical Weather control
ready open overlay ↗

In OBS add a Browser source → index.html (1920×1080, transparent, “shutdown when not visible” off). Run node server.js in the hub folder and open this page from http://localhost:8790/weather/admin.html so edits reach OBS live. The legacy per-app port is opt-in with LEGACY=1; the hub is the default.

Data: Open-Meteo — free, no API key, no signup. Geocoding uses geocoding-api.open-meteo.com; forecasts come from api.open-meteo.com/v1/forecast. Values are cached in the browser so a network hiccup never blanks the panel.

Dark is a curated palette layered over the colours below, so those stay your light design. A single browser source can also force it by adding ?theme=dark to its URL.

Tip: the glass reads best with a tint alpha of 0.30–0.50 over video.

Entrance only — no exit animation (in OBS you hide the browser source). Eases use GSAP syntax: power3.out, back.out(1.4), expo.out…

With node server.js running:
/api/command?action=in · ?action=hide · ?action=refresh
