In OBS add a Browser source → index.html (1920×1080, transparent, “shutdown when not visible” off). Serve this folder over HTTP and open admin.html from the same origin so edits reach OBS live.

Assets are stored by their provider id (bitcoin, avalanche-2, the-open-network) — never by ticker, which is ambiguous across exchanges. Search by name and pick a match; the id is what gets saved. A section may be empty, and the board then says so instead of showing a blank panel.

Everything that sets a size or a position. Type is in Type, colour is in Colour.

Narrowing the panel leaves more stage visible either side. The asset column absorbs the leftover width, so the trend chart grows or shrinks with it.

in the Columns tab

Colour and surface only. Sizes are in Layout, type in Type.

asset absorbs the leftover width; sparkline is the 7-day trend. Hiding a column removes it from columns.order. Sizes are in Layout, header type in Type.

Every type control lives here — sizes, weights and letter-spacing are not duplicated elsewhere.

Every face ships in this folder, so the Windows OBS machine never downloads a font. Segoe UI is the one already installed on Windows. The choice sets the title, tabs, names and numbers together.

Raising a size does not overflow a column: the window stays inside its cell and long text is clipped with an ellipsis. If a number looks tight, widen the panel in Layout.

A short dash runs the length of each trend line, then rests for rest seconds and repeats. One pass every travel + rest seconds, offset row by row.

Entrance only — in OBS you hide the browser source instead of animating out. Eases use GSAP syntax: power3.out, back.out(1.4), expo.out…

The board has no refresh timer. It reads the hub once when it loads; the hub re-reads CoinGecko only when its own 90-second cache is cold, or when you press this button.

Data comes through the overlay's own cached proxy (api/market), then direct, then the last good response in localStorage — ten OBS sources cost one upstream call. Prices and changes are sent live over ?type=cm:config; the endpoints themselves are build-owned and stay in config.js.
