Talking Points Panel control
ready open overlay ↗

In OBS add a Browser source pointing at index.html (1920×1080, transparent). Open this page from http://localhost:8790/topics/admin.html — served by the shared Overlays/server.js — so every change reaches OBS live.

Dark is a curated palette layered over the colours below, so those stay your light design. A single browser source can also force it by adding ?theme=dark to its URL.

Entrance only — there is no out animation (OBS hides the source, the panel never animates away). Eases use GSAP syntax: power3.out, back.out(1.4), elastic.out(1,0.5), expo.out…

With node server.js running you get an HTTP control API:
GET /api/command?action=in · ?action=out · ?action=replay
